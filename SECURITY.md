# Security Policy

## Supported versions

The current `0.1.x` development line is supported with security fixes.

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues or pull requests. Use the repository host's private vulnerability reporting feature, if available, or contact a project maintainer privately through that host.

Include the affected version or commit, steps to reproduce, and potential impact. Please allow maintainers reasonable time to investigate and prepare a fix before publicly disclosing the report.

TerraWatch is an early MVP. Monitoring area records currently live in browser `localStorage`; do not store secrets or sensitive personal information in the application.
